# 线型库解析逻辑总梳理（已验证变体 + 结构参数兜底）

> 当前原则：图形几何首先由库记录自身推导；人工裁定只用于已经验证的变体和辅助检查，不能覆盖库参数。
> 当前公共原始渲染路径：已验证变体优先 `feature_rhythm()`，其他记录使用 `LineStyle.rhythm()` 或选定子线的 `SubLine.parameter_geometry()`（全部实线笔可叠加）。
> 未解决的已裁定变体返回 `None`，不再用通用几何替代。

## 当前混合解析主路径

```
(linetype, aux_linetype)
       │
       ├─ 已验证记录族？
       │      └─ feature_rhythm(style, aux) → 已验证变体几何
       │
       └─ 其他记录
              ├─ LineStyle.rhythm()         # 库内直接节奏结构存在时
              └─ 选定 SubLine.parameter_geometry()  # 否则按变体选择子线；实线笔可叠加

主记录解析后，再判定 aux 角色：
  范围内 aux → 主记录子线变体，不独立叠加（2 号族越界等价裁定为例外）
  越界 aux   → 独立辅助记录，解码后叠加
```

- **记录号 = 线型号（1-based）**；记录 = 子线指针表 + N 条子线。
- **子线 = [u16 n][n×6B 元素模板 (unit, marker, offset)][f32 载荷区]**。
- 已验证变体直接使用既有裁定结果，避免把 offset 误当通用周期；其他记录才使用结构参数推导。
- `parameter_geometry()` 不读取线型号、不查裁定表、不按半径猜填充：显式填充单元输出填充，显式画点单元输出点；其他三点载荷的填充状态为 `None`，由报告记录 `unknown_fill`。
- `unit=0` 不能单独证明空移；载荷中的两个坐标对仍是可见线段，必须保留。
- 非实线子线按变体选择，不得把不同变体叠加。例：`48|0` 只消费子线 0，形成连续基线与平行断线；`48|1` 对应另一变体。全部 24B 实线笔则属于真实叠加层，不能误删。
- 周期同时参考元素 offset 与载荷实际 x 范围，避免把连续基线误截成短段。
- 48 族抬升线的每段起止位置必须来自库内 `(x0,x1,y)`，不得替换为 Matplotlib 固定 `(3,2)` 等屏幕虚线。`x_coef` 缩放周期和段长，`y_coef` 缩放抬升距离；连续基线保留原始折点，非零 y 层使用平行曲线，并以原线链长控制相位。
- 所有零偏移实线（包括 38|2 基线）按原线链长裁切，并保留区间内全部原始折点，不得以周期端点连线替代。全部 37 条真实 38|2 的 782 个源顶点逐点验证缺失 0、最大偏差 0.0：[坐标保真审计](../output/linestyle_38_2_coordinate_fidelity_20261107.json)。
- 非零恒定偏移的平行线使用完整 offset curve，并以原线链长映射相位；不得退化为端点弦线。垂直刻度等纵向分量仍由原线锚点与法线计算。
- 16/17 族同坐标的重复实心圆引用按几何并集合并，保留最大半径；此规则仅适用于同色无描边实心圆，不推广到空圈或其他填充状态。
- `feature_rhythm(style, aux)` 的 `sub[aux]` 是**主记录变体选择**。`compose_feature_style()` 对范围内 aux 返回 `(main, None)`，只有越界 aux 才返回独立辅助记录；2 号族的越界等价虚线裁定不叠加。故 `16|1` 不多出实线，`38|2` 不叠加辅助虚线，`65|4` 必须消费主记录第 4 子线，而 `1|2` 保留独立辅助 2 号虚线。
- 零纵向长度的竖刻度使用半开链长区间 `[0,total)`，避免原点刻度被裁掉，也避免闭合线终点重复；18|0 的起点竖线已纳入回归。

## 二、元素模板语义

| unit | 含义 | 消费 |
|---|---|---|
| 0 | 空移/线对 | marker×2 个 f32 |
| 1 | **坐标列填充多边形**（211/38/208 锚）| marker×2 个 f32（点对）|
| 2 | 随动/档 | marker×2 个 f32 |
| 3 | 画点 | marker×2 个 f32（点对）|
| ≥5 | 子图号引用（258/259 圆点、1280 等）| 同上 |

**消费律通用律（2026-10-20 定案）**：元素模板的 `offset` 字段 =
该元素载荷区的**起始 f32 索引**（全库 984/984 子线成立、0 违例）；
消费区间 = `[offset_i, offset_{i+1})`，末元素到载荷尾。默认
2×marker 律只是 offset 与 marker 一致的特例——变体实证：
388/147/16|0 的 offset 差 3 = (x,y,r) 三元组、差 4 = 线对。
实现：`SubLine.consumption`（不可解诚实 None）+ `payload_groups()`。
**aux 双义例外条款（2026-10-21 用户暂定策略）**：**1|x 等价 1|0 =
单实线；2|x 仅 x>4 时等价 2|0 = 纯虚线——aux 字段不参与渲染**
（用法/编图元数据）。库结构：1 族 1 条子线（库变体仅 1|0）、
2 族 5 条（库变体 2|0–2|4）；越界 aux（1|1/1|7/2|9/2|18 等）是
数据字段对，MapGIS 库界面不存在（用户实证）。2|0–2|4 子线变体
族中 2|1/2|4 有 10-16 纯虚线等价裁定、2|2/2|3 未裁定诚实 None。
**暂定**——若未来某 1|x/2|x 证有形态分化，按图面裁定修订。

**逐元素对账纪律升级**：以 offset 区间为准，marker 仅作校验。

**载荷几何语义（2026-10-20 定案，`SubLine.payload_geometry` 单源）**：
**unit 号不是语义分类依据**（825|0 填充漏画根因——unit=1/513/513
同构填充三单元被 unit==1 判据漏画两个）。判据 = 载荷形状/尺寸：
- 消费区间恰 3 f32 → dot (x,y,r,**filled**)（填充按半径分派——
  2026-10-21 用户裁定族：379|0 r=0.05 空、574|0 大点 r=0.01 空小点
  实、565|0 大点 r=0.10 空小点 r=0.05 实）：
  **r < 0.02 → 实心；r ≥ 0.075 → 空圈；中间带 0.02–0.075 按 unit
  裁定（unit=2 空、unit=3/引用 实——379|0 unit=2 空、16|0/17|0
  引用实锚定）**
- ≥3 对且首尾闭合(<0.003) → fill 填充多边形（825 的 1/513、223 的三环）
- 恰 2 对 → segment 线段
- 其他多对 → polyline 折线
实线笔 → 载荷对本体 segment（575 裁定）。全库烟测 19345 几何元素
全覆盖无孤儿；渲染器一律消费此单源，不得自带 unit 启发式。

## 三、f32 载荷的通用语义模式

1. **坐标对序列**：`(x0,y0), (x1,y1), …`——每对是点或线端点；
   **y 是真实坐标不是噪声**（51|0 教训）
2. **点三元组**：`(x, y, r)`——unit=3 元素（50/51/16|2/58 锚）
3. **档结构**：`(x, y0, y1)` ×N 遍冗余——x=档值（标签非位置）、
   |y0|=刻度高、y1=顶端（3|5/4|3 锚）；**档文件序 = 间隙序**
4. **尾段线**：末尾 6 对 = 三线（连续对成线，y 为噪声忽略）；
   127|0 教训：**尾段元素同样是图形，必须消费**
5. **重复坐标 = 冗余**（153 锚：不叠画不加粗）

## 四、周期规则（两犯教训定案）

- **基本单元等间距族**：周期 = 相邻线起点差的最小正值（38|1：0.5）
- **单线族**：周期 = 最大线终点（48|1：1.0）
- **记录末 x ≠ 周期**（38|1/48|1 教训）

## 六、新线型落码三查纪律（docstring 已制度化）

1. elements 结构先行（unit/marker 消费与角色）
2. (x,y) 对角色判定（线端点/点/参数）——不得套已裁定模板
3. 周期来源（单元间距/最大线终点）
4. 渲染对账：全部元素必须消费（127 教训）
5. 分支守卫：前序分支正向 `style.no == X`（5|0、51 教训）
6. 每行 ≥1 条逐值锚定测试 + 全量回归
