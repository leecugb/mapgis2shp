# Fillgrph.lib 填充图案库解析逻辑总梳理（2026-10-19 定案版）

> 依据：用户目视裁定锚（220/243/247/252/253）+ 全库 1075/1337 结构校验。
> 实现：`pymapgis.fillgrph`（FillgrphLib.decode / pattern_geometry）。
> **核心结论：笔划分组由文件自身编码，渲染不再需要逐图案人工裁定。**

## 一、总架构

```
(Fillgrph.lib, 图案号) ──→ FillgrphLib.decode(no) ──→ FillPattern
                                        │  [grid, unit] + M 条 FillStroke
                     pattern_geometry(no) ──→ {fill_polygons, polylines,
                                        │      circles, arcs}
                     逐笔划消费：kind 决定几何角色，坐标区按对数切片
```

- **记录号 = 图案号（1-based）**；记录 = `[u16 grid][u16 unit]` +
  `M×（10B 笔块 + 2B 对数）` + 坐标区
- 结构定位 = 解方程：`zone = 4 + 12M` 且 `len(记录) - zone == sum(对数)×8`
  （确定性校验，不依赖坐标取值——250/251 首坐标 (0,0) 的旧扫描教训）
- 结构不合的记录（旧式/异型，261/1337）诚实返回 None，绝不臆断

## 二、笔块字段语义

笔块 = `(kind, 0, 0, width, 1)`（5×u16；中间两字段全库恒 0，末字段恒 1）

| kind | 角色 | 载荷（坐标对） | width |
|---|---|---|---|
| 0 | 填充多边形（闭合、填充） | 环顶点序列（首尾闭合） | 0 |
| 1 | 折线 | 顶点序列 | 65535（发丝线） |
| 2 | 折线 | 顶点序列 | 笔宽档（实测 1–7、10、15） |
| 3 | 弧（**角度制**） | `(cx,cy), (r, a0°), (a1°, 0)` | — |
| 4/5/6 | 圆弧族 | 满载 `(cx,cy), (r, 0), (0, 0)`（a0=a1=0 整圆锚定，与子图弧哨兵同源） | — |

## 三、渲染逻辑（逐笔划消费）

1. 笔划内与上一保留点间距 <0.003 的连续点合并（回描/落笔冗余；
   220 线笔划落笔点对相差 0.0001 而非精确相等，须容差判定）
2. kind=0：合并后若首尾闭合（<0.003）去除闭合点 → 填充区；
   kind=1/2：≥2 点 → 折线（1 点落笔冗余剔除）；
   kind=3：角度非零 → 弧；kind=4/5/6 与 kind=3 且 a0=a1=0 → 圆
3. 笔划顺序 = 绘制顺序；同一几何的多次存储（220 的轮廓描边复用
   环坐标）各自输出，忠实保留
