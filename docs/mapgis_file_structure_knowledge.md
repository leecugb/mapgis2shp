# MapGIS 6.x/67 文件结构知识库

**存档日期**：2026-10-18
**来源**：库尔干幅 J43C001002 36 文件、奥依亚依拉克 J45C004001、MapGIS 6.7
原生联调（40+ 轮显示判别）、官方明码对（wat/wal/wap）、原生新建文件（lee.wp）。

---

## 1. 总体布局

```
[文件头 657B][索引区 160B = 16 项 × 10B][数据体从 817 起]
```

- 8B 魔数：点 `WMAP\`D22`、线 `WMAP\`D21`、面 `WMAP\`D23`
- @8 int32 文件标识：点=1、线=0、面=2
- @12 int32 `data_start` = 657
- 索引项 = `[int32 start][int32 volume][2B tail=0xFFFF]`，共 **16 项**
  （旧知识只读 10 项——第 11/12 项是区文件显示必需，见 §7）

### 毫米→度系数公式（原生锚值 0.002906409 / 0.002251664 @1:250000,39.5°N）

```
x = map_scale / 纬线弧长(mm/度)     # 弧长按 CRS 椭球（pyproj.Geod）在中心纬度计算
y = map_scale / 经线弧长(mm/度)
```

**零系数 → MapGIS 符号尺寸归零 → 点/线/面全部不可显示**（显示闸门之一）。

## 3. 属性段（三类型共用，索引位置：点=2，线=2，面=9）

```
[322B 前缀][i16 字段数][i32 记录数][i16 记录长][18B 垫][39B×N 描述符][记录区]
```

- 前缀：@0 FILETIME，@2-3 日期，@12 类型戳（点=621，线=1011，面=972/855 等
  随文件变），@20+ **GBK 路径区**（工作目录，出现两次），@320 `\`D` 签名
- 描述符 39B（struct "<20sBihhih4x"）：`[20B GBK 名][u8 类型][i32 记录内偏移][i16 存储宽][i16 声明宽]
  [i32 标志(串=256,数值=512+小数位)][i16 字段序号][4B 垫]`
- 类型码：0=串，1=byte，2=short，3=int，4=float，5=double，6=日期(i16年+u8月+u8日)，7=时间(u8时+u8分+f64秒)
- 记录区：首条空记录（标志字节 0x01），记录数 = 要素数+1；
  记录 = `[0x01 标志][字段按偏移稀疏布局]`，记录长 = 各字段声明宽累计
- **原生字段布局是稀疏的**（声明宽 ≥ 实际内容，如 MDBTZ 100 字符宽）；
  MapGIS 显示依赖声明宽——密排压缩会被拒绝。往返须逐字节保留描述符与宽度。

## 4. 点文件（.wt）

```
索引：0=坐标(93B/条，首条空)  2=属性
辅段：3=标注框 (n+1)×32B（原生首条为有效框；Writer 写 32B 零前导，显示验收通过）
      4=4B 前导+每点 4B 标志
```

93B 记录：`[u8 标志=1][6B 保留][f64 X][f64 Y][70B 图形参数区]`

图形参数（官方明码 WMAP9022 定案）：
- 子图点（@31=1）：号 u16@33 / 高 f32@37 / 宽 f32@41 / 角 f32@45 / 笔宽 f32@49 / 色 u8@75 / 图层 u8@83
- 字符串点（@31=0）：高 f32@33 / 宽 f32@37 / 间隔 f32@41 / 角 f32@45 / 中文字体 u8@49 / 西文 u8@51 / 字形 u8@53 / 色 u8@75 / 图层 u8@83
- 明码格式：文本点 17 字段（含 "文本"），子图点 14 字段（含 子图号/笔宽）

## 5. 线文件（.wl）

```
索引：0=线索引(57B/条,首条空)  1=坐标(2B 前导+16B/对)  2=属性
辅段：3=结点表(24B/条,首条空)  4=head5(55B 零块)  5=元数据块(392B)
      6=框表(32B/条,n+1 条)    7=4B 前导+每线 4B 标志
```

57B 记录：`[1B=01][1B=02][8B 保留][i32 顶点数@10][i32 坐标偏移@14][39B 图形参数]`

图形参数（官方明码 WMAP9021 序）：线型号 i16@22 / 辅助线型号 u8@24 / 标志 u8@25 /
线色 i16@26 / 线宽 f32@30 / X系数 f32@35 / Y系数 f32@39 / 辅助色 i16@43 /
图层 u8@47 / 透明 u8@48

明码 wal 参数序 = 线型号/辅助/**线色**/线宽/X/Y/辅助色/图层/透明（线色在第 3 位）。

## 6. 面文件（.wp）

```
索引：0=弧索引(57B/条,首条空)  1=坐标+结点表  2=元数据块(645B 起)  3=拓扑(24B/条,首条空)
      4=head5(55B 零块)  5=元数据块(392B)  6=弧框表(32B/条,n+1)  7=4B+每弧 4B 标志
      8=区参数(40B/条,首条空)  9=属性  10=区标注框(32+32n)  12=文件脚(4+4n)
```

- 坐标段（索引 1）：`[u16 0][每结点 (0,结点号) 4B][16B/对 坐标]`（结点=弧端点去重，
  1 起编号）；**新建文件（lee.wp）整表缺省、坐标紧随 u16 前导**（两种原生形态）
- 拓扑 24B：`[i32 结点a][i32 结点b][i32 左区][i32 右区][8B 零]`——重建用左右区号，
  结点列新建文件全 0（显示不依赖）
- 弧记录 = 线记录同布局（记录头 01 02；MapGIS 保存规范化：系数 5.0、图层 0）
- 区参数 40B：kind@0=1 / **类码@1（=区图层，2/9/10；0 不显示）** / 填充色 u8@5 /
  图案 u8@6 / 图案色 u16@9 / 子参数块@12-23=`001b010000c0400000c04001`
- 区标注框（索引 10）：`[u32 3086][28 零][每区 (xmin,ymin,xmax,ymax) f64]`
- 文件脚（索引 12）：`[u32 lead][每区 (u16 0,u16 1)]`
- 弧段分解两种原生形态：老库尔干=整环闭合弧（topo 起止同结点）；新建=按数字化
  结点断链（topo 结点列全 0）。无向边对成链+环比保序为兼容方案。

## 7. MapGIS 渲染显示闸门（原生联调实证清单）

面文件缺任一项 = **区能解析但永不渲染**（无报错，"空"）：
1. **索引第 11 项（区标注框段）**与**第 12 项（文件脚）**——主闸门
2. 头部毫米→度系数 @244/@252 非零（三类型共用）
3. 头部图幅边界框 @304-335 非零
4. 属性段字段声明宽度 = 原生宽度（密排被拒）
5. 区参数类码 @1 与弧图层/标志一致且非零
6. head_5/head_6 尺寸与数据自洽（55×(X+1) / 392+路径长；X 语义未解）
7. 元数据块（head_3/6、属性前缀）含工作目录路径区（内容可零但结构须在）

点/线文件：系数+边界框+辅助段（线 head_5/6/7/8 缺失曾致不显示）。

## 8. 明码导出格式（官方纯文本）

- **wat**（点）：`WMAP9022` + 计数 + 每点一行（文本点 17 字段含 "文本"；子图点 14 字段）
- **wal**（线）：`WMAP9021` + 计数 + 每线 [9 参数, 顶点数, 坐标…, 附加行]
- **wap**（面）：`WMAP9023` + 计数 + 每弧 [9 参数, 结点a,b, 左区,右区, 顶点数, 坐标…]

## 9. 已知未解 / 挂账

- @268 计数 X 的语义（55×(X+1) 相关，疑似标注记录数，无法从几何推导）
- @336 标志字节在点/面间的取值规则（0x80/0x84/0xa0）
- @640-657 头部元数据块结构
- 新建文件与老文件两套弧段分解/结点表形态的转换规则
- 元数据路径区的最小可接受内容（零 vs 真实路径的边界）
- head_9 子参数块 @12-23 的字段语义
