# 第四批 Writer 原生转换审计报告

## 1. 审计范围与结论

本批对照数据位于 `F:\writer_shp_batch4_20261108_flat\`，包括20个 SHP 用例及18个 MapGIS 原生转换结果。全部输入采用高斯-克吕格中央经线75°E、k=1、东偏500000 m、单位米。

结论：**本批证据不要求修改 Writer 生产代码。** Writer 在几何保持、异常输入处理、空值语义和量算字段方面优于本次原生转换结果。主要改进是新增第四批回归、完善发行包数据清单，并明确不应继承的原生缺陷。

原生缺失：

- `03_POINT_MULTIPOINT` 未生成 MapGIS 文件；
- `20_EMPTY_FILE` 未生成 MapGIS 文件。

Writer 对 MultiPoint 显式拆分为3个点并给出警告；对零要素文件可在显式几何类型下写出0要素文件。上述差异不作为 Writer 缺陷。

## 2. 关键发现

### 2.1 原生09存在错误面部件组织，Writer 正确

原生 `09_POLY_BASIC` 的第一个 MultiPolygon 同时包含源三角形和源矩形，第二个 Polygon 又重复该矩形：

- 原生第一个面实际面积为15000 m²，其面积属性却为-5000 m²；
- 原生第一个面的周长为741.421356 m，包含两个面的边长；
- Writer 分别保留三角形和矩形，面积分别为5000 m²和10000 m²，与源 SHP 一致。

因此不能把原生09当作目标拓扑。Writer 当前行为正确。

### 2.2 原生07把其他文件的线写入空记录，Writer 更安全

源 `07_LINE_EMPTY` 含一条正常线、一个 null 和一个空线。原生结果却保留了3条线，其中后两条来自前一个 `06_LINE_MULTI_DUPLICATE` 的 MultiLineString 部件：

- `(500000,4300000) → (500020,4300000)`；
- `(500030,4300000) → (500030,4300020) → (500050,4300020)`。

这些坐标不属于07源文件，说明原生转换在空记录位置复用了先前转换的几何。

Writer 默认明确拒绝空/null几何；`on_empty="drop"` 仅保留07中的有效线。该行为避免了无关几何注入。

### 2.3 原生06丢失 MultiLineString 第二部件，Writer 完整保留

原生06仅输出2条线，保留第一个 MultiLineString 的第一部件，第二部件被丢弃。

Writer 输出3条线，保留重复点、第一部件和第二部件，并显式发出 MultiLineString 拆分警告。几何和属性覆盖更完整。

### 2.4 多处原生量算字段与原生几何不一致

以下原生面积/周长字段不能与其实际几何对应：

- 09：面积属性为-5000 m²，实际第一个面为15000 m²；
- 10：面积属性为83750 m²，实际面为86250 m²；
- 11：带孔外框的面积属性为5000 m²，实际面为7500 m²；
- 18：重复几何的面积属性为0 m²、周长属性为800 m，实际面为10000 m²、周长400 m。

Writer 的面积和周长字段按最终几何计算，上述用例均与几何一致，不复制原生错误量算。

### 2.5 原生把非有限值和空值改为0，Writer 保留语义

- `02_POINT_ATTR_NULL`：原生把 NaN、+Inf、-Inf 全部转为0；Writer 分别保留 NaN、+Inf、-Inf。
- `16_POLY_80_FIELDS`：原生把第三个面的空字段转为0；Writer 保留空值。

不向原生缺陷降级是本轮明确选择。若下游业务要求禁止非有限值，应另行制定显式校验规则，而不是静默转0。

### 2.6 退化面和空面

- 原生14把全同顶点退化面表示为 LineString；Writer 明确拒绝少于3个不同顶点的环，避免写出无意义面。
- 原生15只保留一个有效面，丢弃 null 和空面；Writer 默认拒绝，`on_empty="drop"` 得到同样的一条有效面。

### 2.7 CRS 与默认参数

原生结果的 CRS 均未保留，Writer 能写出有效的 `tmerc`、中央经线75°E、k=1 高斯-克吕格 CRS。坐标值仍与源 SHP 一致。

WT 默认符号号、0.1 mm 高宽、颜色6、0.1 mm 笔宽，以及 WL 的实线、颜色1、0.05 mm 线宽、X/Y=1、`aux_flag=1` 均与原生一致。

WP 的 class 和 fill_color 由原生转换过程自动分配，随要素变化，且转换设置未提供，不能据此强设为 Writer 默认值。显式用户参数仍优先。

### 2.8 大环和字段容量

- `17_POLY_LARGE_RING` 的24位组合环索引偏移在 Writer 与原生结果中均为 **81,650**。
- 80个附加字段及中文字段均保留，未发现字段错位。
- 257条点记录及10001个线顶点均完整写回。
