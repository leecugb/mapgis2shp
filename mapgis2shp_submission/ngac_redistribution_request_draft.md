## 使用目的与方式

上述文件仅用于开源 Python 软件 mapgis2shp 的读取、写出、图形库解析、原始图形库渲染和持续集成测试。测试不会修改原始坐标、地质单元或图形库内容，也不用于坐标扰动、虚拟地质单元构造或商业服务。

拟公开或已经公开的渠道包括：

- GitHub 开源仓库及持续集成产物；
- PyPI wheel 和 source distribution；
- 与软件论文配套的复现材料；
- Zenodo 软件归档。

软件本体采用 Apache-2.0。我们明确声明该许可证不重新许可上述源数据或 SLIB，源数据及 SLIB 仍遵循其原有条款。稿件和清单中均保留数据集 DOI、图幅号、生产与分发机构以及获取渠道。
